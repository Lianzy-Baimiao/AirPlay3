# AirPlay3 Rust 重写版 · 产品需求文档（PRD）

> 经典软件回归计划 · 第一步。最后更新：2026-10-12（v3.5.0）

## 1. 背景

AirPlay3（airplayme.com，最后版本 2012-07-30）是一款界面极简、深色、由多个吸附在一起的小窗口组成的本地音乐播放器。官方服务器早已关闭（在线歌词、图片、电台、自动更新、统计全部失效），原程序在新系统上已不可用，也存在连接到被重新注册域名的风险。本项目只依据原版 `AirPlay3.exe`（逆向其资源、字符串、行为），用 Rust 重写，让它在 Windows 10 / 11 上重新可用。

## 2. 目标

1. **界面与原版一致**（最高优先级）：布局、尺寸、字体、颜色、半透明效果、动画、菜单文字、交互手感（吸附、对齐、拖动）尽量逐像素复刻；图标、标志等照着原版的样子自己画，不使用原版的图片。
2. **本地播放可靠**：常见格式、无缝衔接、CUE、续播；不卡顿、不假死、关闭即退出。
3. **替代已关闭的在线服务**：用免费、无需密钥的公开服务下载歌词与专辑图片，并保存到本地。
4. **绿色单文件**：免安装，配置与曲库放在程序旁 `AIRPLAY_CONFIG`。

## 3. 设计原则

- 界面最重要：不做"风格相近"的重新设计；与原版不同的地方视为缺陷。
- 行为照搬原版：能从原程序逆向出来的规则（如吸附阈值 12 像素、面板脱离规则、尺寸范围）照原样实现。
- 隐私：只有用户主动下载或开启自动下载时才把 标题 / 艺人 发给第三方服务；默认不自动联网。
- 原版的在线服务已不存在，不伪造、不连接原域名。

## 4. 目标用户

怀念 AirPlay3 的老用户，以及想要一个轻量、好看、离线可用的本地播放器的用户（以中文用户为主）。

## 5. 功能需求

### 5.1 界面（与原版一致）
| 模块 | 要求 |
|---|---|
| 播放条 304×68 | 空闲：封面、AIRPLAY、轮换标语（乐声飞扬 聆听彼此 / link between souls）、进度与时间；悬停淡入音量、上一首/暂停/下一首、窗口按钮（最小化、迷你条、置顶、关闭）、面板开关、播放模式 |
| 歌词图片 | 说明文字、大封面 + 信息浮层；有歌词时切换小封面 + 滚动歌词（当前行橙色）；空闲显示 airplay 标志 |
| 均衡器 | 前置放大 + 10 段、启用 / 重置 / 预设 |
| 音乐列表 | 工具栏、左侧列表标签、斑马线、悬停 ▶ ×、底部数量与总时长、拼音首字母搜索 |
| 迷你条、桌面歌词、任务栏歌词 | 原版迷你条两条；桌面歌词（原版没有）卡拉 OK 填色、8 种预设配色、可锁定穿透、拖边调整大小且行数随高度变化（1 ~ 12 行）；任务栏歌词靠左 / 居中 / 靠右 + 水平、垂直偏移（拖动或「配置 → 桌面歌词」） |
| 菜单 | 原版文字与顺序（主菜单、列表、歌词图片右键等） |
| 配置窗口 | 基本设置、音频设备、歌词图片、桌面歌词、网络连接、全局热键、文件关联、颜色透明（整体颜色、焦点颜色、边框透明、透明雾化；默认与原版相同：#202020、#FFA040、边框完全透明） |

### 5.2 窗口行为（照搬原版）
- 面板靠近屏幕工作区、任务栏或其它面板 12 像素内自动吸附对齐。
- 拖播放条：与它直接 / 间接贴着的面板整组移动；拖面板标题条或空白处：只移动该面板（脱离），靠近后重新吸附。
- 音乐列表、歌词图片可从左、右、下边及左下、右下角调整大小，被拖动的边自动对齐；尺寸范围与原版一致（列表 264×225 ~ 804×821，歌词图片 284×225 ~ 804×821）。
- 播放条宽度可在 284 ~ 804 像素间调整：音量、封面、标题靠左，大按钮居中，窗口按钮、开关、模式、总时长靠右，进度条拉伸。
- 各面板位置、大小、显示状态都保存；拔掉显示器后回到默认位置。
- 单实例；关闭即完全退出；可最小化到托盘。

### 5.3 播放
- 格式：MP3 / FLAC / OGG / WAV / AIFF / M4A（AAC、ALAC）/ WMA / AC3 / DTS / APE / TTA / WavPack / Musepack / TAK 等；列表 m3u / m3u8 / pls / wpl / asx / xspf / ttpl / apl；CUE 分轨。APE、TTA、WavPack、Musepack、TAK、DTS 用自带解码器（`audio::codec`），要求与参考解码器逐样本一致；改写自 LGPL 代码的解码器（TAK、DTS）放在单独的目录、以 LGPL 发布。DTS 用 FFmpeg 的定点算法（与 `-flags bitexact` 比），支持 .dts / .dtshd / WAV 里的 DTS，含 DTS-HD MA 无损；不支持 DTS Express。
- 无缝衔接、WASAPI 共享 / 独占、均衡器、播放模式、续播上次位置、全局热键、系统媒体控制（SMTC）。

### 5.4 歌词与图片
- 本地：同名 .lrc、`艺人 - 曲目.lrc`、模糊匹配、内嵌歌词与封面、文件夹图片；GBK / UTF-8 / Big5 自动识别。
- 在线歌词：专门的歌词 API，可在配置中选择，默认「自动」同时搜索：
  - LrcAPI（api.lrc.cx，开源项目 HisAtri/LrcApi 的公开实例）：中文歌覆盖最好，同时提供专辑图片；
  - LRCLIB（lrclib.net）：开放歌词库，欧美歌为主。
  - 搜索前清理标题与艺人（去掉版本说明、音质标记、来源水印、曲目编号、多位艺人）；服务器繁忙自动重试；搜不到时只按标题搜；自动下载只接受时长相差 5 秒内的同步歌词；手动搜索窗口可修改条件、选择结果，并标出来源。
  - 不直接调用音乐平台（QQ 音乐、网易云、酷狗等）未开放的接口。
  - 可填写自建 LrcAPI 的地址与密钥（「配置 → 网络连接」）。
- 在线专辑图片：LrcAPI，找不到时用 iTunes Search API，都按时长匹配。
- 艺人图片（原版「下载艺人图片」）：没有专辑图片时显示。Deezer 公开 API（官方文档、无需登录）按艺人名搜索，繁简视为相同（Windows LCMapStringEx 转简体后比较）；没有时用中文维基百科条目配图（简介须提到歌手 / 乐队等）。按艺人缓存，两个来源都没有的艺人 7 天内不再联网；连不上时 10 分钟内不再自动尝试。
- 下载后自动修改歌曲信息（原版选项，默认关闭）：歌名一致、时长相差 3 秒内时补全空着的艺人、专辑，只改曲库。
- **下载后自动保存到本地并关联到歌曲**：歌词 → 自定义歌词目录或 `AIRPLAY_CONFIG\LYRIC`；图片 → `AIRPLAY_CONFIG\CACHE\COVER`。
- 手动关联 / 取消关联本地歌词与图片，歌词快慢微调。

### 5.5 网络电台
- 原版「音乐导航 / 精选电台」已关闭。
- 「网络电台」窗口：推荐（按地区）/ 热门 / 收藏 / 搜索（名称，找不到再按标签）。
- 播放：自带下载线程（ICY 元数据取节目名、HLS 轮询分段、MPEG-TS 解复用、断线重连），ADTS / MP3 分帧后交给 Media Foundation 解码（HE-AAC 完整音质）；直播不能跳转。
- 「正在播放」：电台名、当前节目（ICY StreamTitle）、地区与标签、电台图标；上一首 / 下一首在当前电台列表里切换；收藏存在配置里。

## 6. 非功能需求

- 性能：界面线程不得被阻塞；任何操作不出现"未响应"；拖动、动画流畅（30 帧）。
- 稳定：配置与曲库原子写入并保留 .bak；损坏时自动回退。
- 兼容：Windows 10 / 11 64 位，高 DPI（与原版一样按 1:1 像素绘制）、多显示器。
- 体积：单个 exe，约 7 MB。

## 7. 不做

- 原版的 MSN 分享、在线更新、统计等服务（服务器已关闭）。

## 8. 验收

- 与原版截图（沙盒中运行原版截取）对比，布局逐像素一致。
- 吸附 / 脱离 / 调整对齐的结果与在沙盒中对原版做的同样操作一致（见 `src/gui/snap.rs` 测试）。
- 自测脚本回放常用操作（音量、进度、滚动、切歌、右键各面板、开关、配置窗口、歌词搜索）无卡顿，关闭后进程退出。
- 每个版本：单元测试通过、release 构建无警告、`dist/` 同步、提交并推送 GitHub、发布 Release。
